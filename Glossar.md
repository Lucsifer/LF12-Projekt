# Glossar
|Begriff|Beschreibung|
|--|--|
|Summoner|Spieleraccount in League of Legends, eindeutig identifiziert durch Summoner Name und Summoner ID|
|Riot Games API|Offizielle Programmierschnittstelle von Riot Games, über die Spieldaten wie Match‑History, Ranglisten oder Summoner‑Informationen abgerufen werden können.|
|Match Data|Strukturierte Spieldaten eines einzelnen Matches, z. B. Kills, Deaths, Assists, Gold, Items, Spielzeit.|
|Champion|Spielbarer Charakter in League of Legends, dessen Statistiken über die API abrufbar sind.|
|Next.js|React‑basiertes Webframework für serverseitiges Rendering, API‑Routen und performante Webanwendungen.|
|Tailwind CSS|Utility‑First‑CSS‑Framework, das schnelle und konsistente Gestaltung von Benutzeroberflächen ermöglicht.|
|GUI (Graphical User Interface)|Grafische Benutzeroberfläche der Webapp, über die Nutzer Summoner‑Daten eingeben und Ergebnisse sehen.|
|Node.js|JavaScript‑Laufzeitumgebung für serverseitige Anwendungen|
|Express|Minimalistisches Webframework für Node.js, häufig genutzt für API‑Routen.|
|API‑Endpoint|Eine spezifische URL, über die Daten von der Riot API oder der eigenen Backend‑API abgerufen werden.|
