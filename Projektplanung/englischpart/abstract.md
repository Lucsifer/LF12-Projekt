# Abstract League of legends Summoner Webapp

Online games generate large volumes of real-time data. Players increasingly rely on external tools to access accurate statistics. Existing League of Legends platforms often lack customization, transparency or modern infrastructure. To address these limitations, we developed a personalized Summoner Stats Webapp. While creating a scalable and repeatable architecture for upcoming IT projects, we also explored the capabilities of the Riot Games API. The goal was a secure and maintainable system that delivers reliable data through a clean and intuitive interface. This demonstrates how software engineering may be used in a game setting.

The system uses a Next.js frontend styled with Tailwind CSS. A Node-based backend handles structured communication with the Riot API, while a Redis caching layer reduces API load and improves response times. PostgreSQL provides persistent data storage. The application runs on a Hetzner cloud server via Docker and docker-compose. Nginx serves as a reverse proxy with HTTPS for secure public access. Uptime Kuma monitors system stability, and a GitHub Actions CI/CD pipeline automates deployment with little manual intervention. Together, these components form a practical blueprint for data-driven applications requiring reliability and scalability.

The result is a fully functional web application that retrieves Summoner data quickly and presents it through a responsive interface. Caching and containerization improve performance noticeably, while automated deployment enables rapid updates with minimal downtime.

The project shows that modern web technologies and organized infrastructure design can be combined to build efficient digital services. It also provides practical insights into API integration, caching strategies, and cloud-based deployment. These findings underline the value of clean architecture and automation, especially for applications that process real-time data.
