# Exampel Abstraced
Online games generate large amounts of real‑time data, and players increasingly rely on external tools to access accurate and fast statistics. Existing League of Legends platforms often lack customization or transparency regarding their technical foundations. As active players, we developed a personalized Summoner Stats Webapp to explore the capabilities of the official Riot Games API and to design a modern infrastructure that can be reused for future IT projects. The goal was to create a secure, scalable, and maintainable system that delivers reliable data through a clean and intuitive interface.

The project combines a Next.js frontend styled with Tailwind CSS, a Node‑based backend that communicates with the Riot API, and a Redis caching layer to reduce API load and improve response times. PostgreSQL is used for persistent data storage. The application runs on a Hetzner cloud server and is deployed through Docker and docker‑compose. An Nginx reverse proxy with HTTPS ensures secure public access. System stability and uptime are monitored with Uptime Kuma, while a GitHub Actions CI/CD pipeline automates the deployment process and minimizes manual maintenance. This setup reflects a practical and transferable architecture for data‑driven applications.

The final result is a fully functional web application that retrieves Summoner data quickly and presents it through a responsive and visually appealing interface. Caching and containerization significantly improve performance, and the automated deployment pipeline enables rapid updates. The project demonstrates how modern web technologies and structured infrastructure design can be combined to create efficient and reliable digital services.
